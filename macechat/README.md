# MaceChat

A responsive, colorful chat UI built with Vite.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Current functionality
- Responsive desktop and mobile layout
- Switch between sample conversations
- Send messages and save them in browser localStorage
- Add local sample contacts
- Filter contacts by status
- Search and clear the current local conversation
- Light/dark appearance toggle

## Important
This is a front-end starter. Messages are stored only in the current browser. It does not yet provide accounts, a shared database, or real-time messaging between different people.
